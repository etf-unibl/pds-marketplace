# pds-datasheet

Reading the timing of a component datasheet (PDF) for the PDS course: finds the timing tables and diagrams, explains what each parameter means (setup, hold, clock-to-output, access and hold times, test conditions, min/typ/max) and helps you choose the values that match your board, collected in a timing card that pds-quartus uses to teach the timing constraints (SDC) you calculate yourself.

Part of the [PDS plugins](https://github.com/etf-unibl/pds-marketplace) marketplace. Skills: `datasheet`. Tools: `pds-mcp --profile datasheet` from [pds-tools](../../tools/pds-tools) (install it in the course virtual environment).
