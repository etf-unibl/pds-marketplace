# pds-learning

Learning companion for the PDS course built on the course material: topic pages of the 15 video lectures with video moments, verified example code (runnable with GHDL), notes on errors in the videos, glossary (Serbian and English) and self-check questions. Hints and explanations, no solutions of graded tasks.

Part of the [PDS plugins](https://github.com/etf-unibl/pds-marketplace) marketplace. Skills: `examples`, `glossary`, `quiz`, `tutor`. Tools: `pds-mcp --profile learning` from [pds-tools](../../tools/pds-tools) (install it in the course virtual environment).
