# pds-testing

Testbenches for the PDS course: self-checking patterns, test vector tables, procedures, file-based tests, clock and reset, running them exactly like the course CI with GHDL (VHDL-2008) and reading the results.

Part of the [PDS plugins](https://github.com/etf-unibl/pds-marketplace) marketplace. Skills: `run`, `testbench`. Tools: `pds-mcp --profile testing` from [pds-tools](../../tools/pds-tools) (install it in the course virtual environment).
