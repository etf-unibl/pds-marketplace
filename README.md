# pds-docs

Design documentation (Doxygen --! comments) for the PDS course: drafts a documentation skeleton in your design file (brief descriptions of the file, entity, ports, architecture, processes and signals, with TODO placeholders for the detailed descriptions you write yourself), reviews your documentation against the course requirements and Doxygen's pitfalls, and builds the HTML pages locally so you see them before GitHub Pages publishes them.

Part of the [PDS plugins](https://github.com/etf-unibl/pds-marketplace) marketplace. Skills: `document`, `preview`, `review`. Tools: `pds-mcp --profile docs` from [pds-tools](../../tools/pds-tools) (install it in the course virtual environment).
