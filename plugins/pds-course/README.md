# pds-course

Course workflow of PDS: setup check, task context, pull request description, failed CI checks and time tracking. Teaches the workflow, never runs it.

Part of the [PDS plugins](https://github.com/etf-unibl/pds-plugins) marketplace. Skills: `checks`, `setup`, `submit`, `task`, `time`. Tools: `pds-mcp --profile course` from [pds-tools](../../tools/pds-tools) (install it in the course virtual environment).
