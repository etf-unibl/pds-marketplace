# pds-git

Git coach for the PDS course: branch from an issue, commit messages in the course format, push and sync, merge conflicts, fixing mistakes. Shows and explains every command; the student runs it.

Part of the [PDS plugins](https://github.com/etf-unibl/pds-plugins) marketplace. Skills: `commit`, `fix`, `start`, `sync`. Tools: `pds-mcp --profile git` from [pds-tools](../../tools/pds-tools) (install it in the course virtual environment).
