# pds-quartus

Intel Quartus Prime for the PDS course, for students and instructors: creates a project for a design (DE1-SoC device, VHDL-2008, board pins, clock constraint) outside the repository, runs synthesis or the full compilation, analyzes timing (slack, Fmax, worst paths) and helps close it, writes and runs Tcl scripts, and programs the board. Shows the commands and Tcl it uses, so you learn the command-line flow.

Part of the [PDS plugins](https://github.com/etf-unibl/pds-marketplace) marketplace. Skills: `compile`, `program`, `project`, `tcl`, `timing`. Tools: `pds-mcp --profile quartus` from [pds-tools](../../tools/pds-tools) (install it in the course virtual environment).
