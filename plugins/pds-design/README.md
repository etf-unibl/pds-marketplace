# pds-design

Design review for the PDS course: VHDL style rules explained, synthesis warnings (latches, sensitivity lists), resources and timing from Quartus reports, DE1-SoC pin mapping and board testing.

Part of the [PDS plugins](https://github.com/etf-unibl/pds-marketplace) marketplace. Skills: `pins`, `style`, `synthesis`. Tools: `pds-mcp --profile design` from [pds-tools](../../tools/pds-tools) (install it in the course virtual environment).
